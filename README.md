# あらまし
ようこそ！
このリポジトリは、 S-at-0[^1] が編み出した PKM およびオントロジーシステムの **Personal Knowledge μουσική** [^2] を動かすために作られた、Obsidianのカスタマイズ済み保管庫です。

ご利用前に、[マニュアル](http://www.warabi.ne.jp/~s_at_0/PKmu/) へ予めお目通しお願いします。(未完成)
## 立ち上げ
このリポジトリは、この配信元の履歴を照らし合わせながらアップデートを自動的にインストールするため、 [Github Importer](https://github.com/new/import) による導入をお勧めします。
1. Githubアカウントがない方は作成します。
2. 今開かれたこのサイトのリンクをコピーします。
3. 上のリンクを開き、下のように埋めます。
	- username, access token は空欄のままで構いません。これは公開されたリポジトリだからです。
	- 一番下の選択は、私的なノートを扱うならば ==Privateにすること== を強く推奨します。
4. Begin importを押し、しばらく待機。終わったらリポジトリをクローン (`git clone` またはGitプラグインの手順に従う)
![Github Importerの画面](SrcBarn/26-242-1151/インポート画面.jpg)
### セットアップ
Gitの競合を回避するため、いくつかの設定は外部に取り置かれています。

## 基本操作
![[26-242-3301|]]

主なホットキーは下の通りです。
- 設定: ==⌘ ⇧ ' , '== iPad 「設定...」 との競合を防ぐため。
- コマンドパレット: ==⌘ ⇧ Space== Spotlight にインスパイア。
- クイックスイッチャー: ==⌘ ⇧ Enter== 本当は⌘⇧⌥Space とかにしたかったのですが...WindowsやLinuxで割り当て済みにつき断念。

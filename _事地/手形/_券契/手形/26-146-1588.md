# あらまし
実際には、仕組みをサネで仕分ける仕組み。返される仕組みは、
- 使われる仕組み(khora)
- 対象となるサネ(topos)
この２つのリンクをカタに含む時選ばれる。返り値は ~~`dataview array proxy`~~Array。バグ防止のため
# 仕掛け
### 仕組み方
```JS
const [
	{arche,transDunamis,Mneme:{cascade}},
] = await syzygy('26-146-1588');
```
```JS
export default function (...morphe){
	const [khora, topos] = morphe.map(x=>transDunamis()(x).path);
	const isKhora = hyle => [khora,topos]
		.every(x =>cascade(hyle).map(x=>x.file.path).includes(x));
	return dv.pages(`[[${khora}]]`)
		.where(isKhora)
		.sort(x => x[arche.prop.time],"desc")
		.array();
}
```

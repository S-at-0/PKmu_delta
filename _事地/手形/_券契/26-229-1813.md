# あらまし
Macの `^control` キーと `⌘command` キーは、Windows・LinuxなどIBM配列で `Ctrl` に割り当てられ、競合が生じやすい。Commandは見た目がWinキーに似るため、そこに割り当てる。
- Ctrlおよびcommand: `Mod`
- winおよびcommand: `meta`

> [!note] ControlはMacから
> Windows・Linuxから `Ctrl` を叩くと`Mod` になる。
> Macの `^Control` は`Ctrl` として登録され、どの端末もControl相当のキーを指す。
# 仕掛け
### 仕組み方
```JS
const isModule = true
```
```js
const noesis = async function(){
	//await syzygy('26-229-1813');
	//ここに仕掛けの流れを記す
	const dunamis = app.vault.configDir + "/hotkeys.json";
	const hyle = await app.vault.adapter.read(dunamis);
	await app.vault.adapter.write(dunamis,hyle.replaceAll("Mod","Meta"))
		.then(_=>new Notice("Completed!"));
};
if(typeof isModule === "undefined") noesis();
```
